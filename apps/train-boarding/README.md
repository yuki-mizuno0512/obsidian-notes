# のりば手帳

「電車のノリ場所」メモをアプリにしたものです。`index.html` を開くだけで動きます
（ビルド不要・通信不要・1ファイル完結）。

- **アプリ本体** … [`index.html`](index.html)
- **元メモ** … [`source-memo.md`](source-memo.md)

## 使い方

スマホのブラウザで `index.html` を開き、**ホーム画面に追加**するとアプリのように使えます。
オフラインでも動きます（フォントも埋め込み済み）。

- **1枚のカード＝ひとつの行き先。** エスカレーター / エレベーター / 階段は同じカードの中に並びます。
  切り替えボタンにも号車-ドアが出ているので、押さなくても見比べられます
- 上の検索欄に駅名や路線を入れるとしぼり込めます（例: `高円寺` `原宿` `JB`）
- **行き / 帰り**、**エスカレーター / エレベーター**、**★お気に入り** で絞り込み。
  目印でしぼると、各カードもその目印を開いた状態になります
- ★ を押すとお気に入り。よく使うのりばだけ表示できます
- ✎ で編集、右上の ＋ で新しいのりばを追加。
  目印ごとにのりばを足せて、それぞれに複数路線の乗り継ぎも登録できます
- ◐ で 自動 / 明るい / 暗い の切り替え

追加・編集・お気に入りはブラウザの localStorage に保存されます。
別の端末へ移すときは、下部の **追加分を書き出す → 読み込む** で JSON をコピーしてください。

## 表記のルール

| 表記 | 意味 |
| --- | --- |
| `10-2` | 10号車 2番ドア |
| `3号車 ・ 4号車寄り` | 号車だけ分かっている場合 |
| 編成図 | 号車の並び。当たりの車両が路線カラーで塗られる |
| ドア図 | 車両内のドア位置。**前から**数える（元メモの「3号車の前から3番目の扉」＝ `3-3`）|

## 元メモから解釈した点

アプリ化にあたって、次の3つは元メモのままだと数が合わないため
**要確認**タグを付けて、原文を各カードに残してあります。

1. **rana行きの山手線「2|4」** … 2号車4番ドアと読みました。
2. **TX / 東京駅乗り換え「8-4・9-1」** … つくばエクスプレスは6両編成で東京駅に乗り入れていないため、
   路線名の解釈が未確定です。編成図は出していません。
3. **東京駅→高円寺の「3-5」** … 中央線快速は4扉なので5番ドアが存在しません。

また「山手線＋中央線」は元メモが「ん？」だけだったので、
空のカードを置いてあります（✎ から書き足せます）。

## 1枚にまとめた組み合わせ

元メモでバラバラに書かれていたものを、同じ行き先ごとに1枚へ寄せています。

| カード | まとめた中身 |
| --- | --- |
| → 高円寺（総武線） | エスカレーター `4-2` ／ エレベーター `5-2` |
| 高円寺 → 四ツ谷 | エスカレーター `10-2` ／ 階段 `8-4` ／ エレベーター「もっと後ろ」 |
| 新宿 → 高円寺 | エスカレーター `8-1` ／ エレベーター `3号車・4号車寄り` |
| 山手線 → 高円寺（新宿乗り換え） | 指定なし `8号車 一番後ろ` ／ エレベーター `山手 7-3 → 総武 5-2` |
| 高円寺 → rana | 指定なし `山手 2-4` ／ エレベーター `山手 5-3`（中央線と新幹線は共通） |

「エレベーター `3号車・4号車寄り`」は元メモに出発駅の指定がなかったため、
中央線で高円寺に着くとき共通の情報として **新宿 → 高円寺** のカードに入れ、
その旨をカード内のメモに書いてあります。

## JR側を調べて分かったこと（2026年8月時点）

カードの下の「◯◯駅 設備の位置を見る」を開くと、公開されているホーム設備の位置が出ます。
**自分で確かめた数字ではない**ので、元メモとは別枠にしてあります。

### メモと一致した（＝そのままで正しそう）

| メモ | 調べた結果 |
| --- | --- |
| 総武線 →高円寺 エスカレーター `4-2` | 高円寺1番線 エスカレーター `4-2` ✅ |
| 総武線 →高円寺 エレベーター `5-2` | 高円寺1番線 エレベーター `5-2` ✅ |
| 高円寺→四ツ谷 エスカレーター `10-2` | 四ツ谷1番線 エスカレーター `10-2` ✅ |
| 高円寺→原宿 山手 `4-2` | 原宿1番線（内回り）階段 `4-2` ✅ |
| 恵比寿 埼京線 `2-3` は階段 | 恵比寿3番線 階段 `2-3`（西口・日比谷線側）✅ |

### 足したもの

- **高円寺1番線に階段 `6-3`** … メモになかったので追加
- **四ツ谷1番線のエレベーターは `9-2`** … メモの「えれべーたはもっと後ろ」の号車が埋まりました
- **恵比寿はエスカレーター `5-3` / エレベーター `4-3`（西口）** … 階段しか書いていなかったので追加。
  東口・ガーデンプレイス側はエスカレーター `6-3` / 階段 `9-2`
- **原宿2番線（外回り）** … エスカレーター `10-4` `7-4` / エレベーター `10-2` `7-2` / 階段 `8-3` `5-2`
- **中野8番線（快速 上り）** … エスカレーター `3-4` / 階段 `1-1`（乗換専用）`6-1`

### 運行・編成の注意

- **中央線快速は土曜・休日は高円寺を通過します**（阿佐ケ谷・西荻窪も）。
  休日は総武線各停か、中野で乗り換えになります。該当カードに注意書きを出しました
- **中央線快速は2024年10月からグリーン車入りの12両編成**。
  4・5号車がグリーン車で**2扉**なので、編成図では G の網かけ、ドア図は2つだけ出します
- 号車の向き … 中央線快速は **1号車が東京寄り**、山手線は **外回りだと1号車が先頭**（内回りは11号車が先頭）

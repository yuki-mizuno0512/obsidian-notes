# のりば手帳

「電車のノリ場所」メモをアプリにしたものです。`index.html` を開くだけで動きます
（ビルド不要・通信不要・1ファイル完結）。

- **アプリ本体** … [`index.html`](index.html)
- **元メモ** … [`source-memo.md`](source-memo.md)

## 使い方

スマホのブラウザで `index.html` を開き、**ホーム画面に追加**するとアプリのように使えます。
オフラインでも動きます（フォントも埋め込み済み）。

- **1枚のカード＝ひとつの行き先。** エスカレーター / エレベーター / 階段は同じカードの中に並びます。
  切り替えボタンにも号車-ドアが出ているので、押さなくても見比べられます
- 上の検索欄に駅名や路線を入れるとしぼり込めます（例: `高円寺` `原宿` `JB`）
- **行き / 帰り**、**エスカレーター / エレベーター**、**★お気に入り** で絞り込み。
  目印でしぼると、各カードもその目印を開いた状態になります
- ★ を押すとお気に入り。よく使うのりばだけ表示できます
- ✎ で編集、右上の ＋ で新しいのりばを追加。
  目印ごとにのりばを足せて、それぞれに複数路線の乗り継ぎも登録できます
- ◐ で 自動 / 明るい / 暗い の切り替え

追加・編集・お気に入りはブラウザの localStorage に保存されます。
別の端末へ移すときは、下部の **追加分を書き出す → 読み込む** で JSON をコピーしてください。

## 表記のルール

| 表記 | 意味 |
| --- | --- |
| `10-2` | 10号車 2番ドア |
| `3号車 ・ 4号車寄り` | 号車だけ分かっている場合 |
| 編成図 | 号車の並び。当たりの車両が路線カラーで塗られる |
| ドア図 | 車両内のドア位置。**前から**数える（元メモの「3号車の前から3番目の扉」＝ `3-3`）|

## どの数字を信じるか

**元メモ（実際に乗って確かめた数字）が正です。** カードに出ている数字は元メモのものです。

いちど「調べた値」に書き換えましたが、**戻しました**。理由は次のとおりです。

- この環境からは出典ページを直接開けず（ネットワーク制限）、**検索結果の要約だけ**を頼りにしていた
- 実際、高円寺3・4番線は検索するたびに違う数字が返ってきた
  （ある回は「3番線のエレベーターは 5-1」、別の回は「3-1」）
- ホームの番線と方向を取り違えている可能性も排除できなかった

なので調べた値は **参考情報** の位置に下げてあります。

- カードの数字 … 元メモそのまま。切り替えボタンが**実線**
- 「参考: ◯◯との情報あり（未検証）」の行 … 調べた値。元メモと違うときだけ出ます
- カード下の「◯○駅 設備の位置を見る」 … 調べたホーム設備の一覧（未検証）
- 切り替えボタンが**破線**のもの … 元メモに無く、調べて足しただけの値

元メモに無い目印（エスカレーター／エレベーター／階段のうち書いていないもの）は、
**勝手に埋めないようにしました**。実際に乗ったときに ✎ から足してください。

## 比較的たしかだと思われること

出典を読めていないので設備位置の数字は保証できませんが、
次の3つは複数の情報が一致していました。

- **中央線快速は土曜・休日は高円寺を通過します**（阿佐ケ谷・西荻窪も）。
  休日は総武線各停か、中野で乗り換えになります
- **中央線快速は2024年10月からグリーン車入りの12両編成**。
  4・5号車がグリーン車で**2扉**（編成図では G の網かけ、ドア図は2つだけ）
- 号車の向き … 中央線快速は **1号車が東京寄り**、山手線は **外回りだと1号車が先頭**（内回りは11号車が先頭）

そして、**元メモの数字が10両編成だった頃のものなら、中央線の号車番号は現在とずれている可能性があります**。
12両化のとき停車位置を東京方か高尾方にずらした駅があるためです。ここは実際に確認するしかありません。

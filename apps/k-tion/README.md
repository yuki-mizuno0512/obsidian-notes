# K-tion Cockpit

Galaxy Z Fold8 向けの個人ダッシュボード（コックピット）プロトタイプ。
折りたたみを開くと、5つの Notion データベースが **グランス画面 → 2ペインの司令室** へリフローします。

## 使い方
`apps/k-tion/index.html` をブラウザで開くだけ（依存ライブラリなしの自己完結HTML）。
上部の `折 / 開` トグルで Fold8 の開閉を切り替え、`◐ Theme` でライト/ダークを切り替えできます。
PC ブラウザでも、Fold8 実機ブラウザでも動作します。

## 画面（Notion 5DB 連携を想定）
| # | DB | 内容 |
|---|----|------|
| 1 | K-tion_Tasks | タスク名・ステータス・S/A/B/C ランク・期限・インボックス |
| 2 | K-tion_Works | 案件名・報酬金額・進捗・クライアント・納期（今月報酬の自動集計） |
| 3 | K-tion_Finance | 取引名・金額・収支区分・日付（手元資金/入金予定の可視化） |
| 4 | K-tion_Schedule | 予定タイトル・期間・カテゴリ・進捗率（ガントチャート表示） |
| 5 | K-tion_Canvas | メモタイトル・手書き画像・作成日時（フリーボード） |

## 現状 / 次のステップ
- 現在の表示データは **すべてモック**（UI とリフローの確認用）。
- 次段階: Notion API 連携（各 DB の読み取り → カードへバインド、書き込みで実データ更新）。

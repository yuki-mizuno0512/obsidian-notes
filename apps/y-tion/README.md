# Y-tion Cockpit

Galaxy Z Fold8 向けの個人ダッシュボード（コックピット）。
折りたたみを開くと **今日のフォーカス → 2ペインの司令室** へリフロー。
ふんわりパステル（ラベンダー×ピーチ×ミント）、ライト/ダーク両対応。

## 使い方
`apps/y-tion/index.html` をブラウザで開くだけ（依存ライブラリなしの自己完結HTML）。
`折 / 開` で Fold8 の開閉、`◐ Theme` でライト/ダーク切替。

## カード
- ⭐ 今日のフォーカス（Work/Private/MTG 横断）
- 💼 タスク Work（NotionのMTG議事録アクションアイテム）🔗Notion同期
- 🏡 タスク Private（Notion「パーソナルタスク」）🔗Notion同期
- 📅 今日のMTG / 🗓️ 今週のスケジュール（パツパツ度）
- 🌿 今日の型 / 🔥 稼働中の習慣（実践ノート連携）
- 📥 要対応インボックス（メール/Messenger/経費）

## データ連携・同期
- このリポジトリの `index.html` は **個人データを含まないテンプレート**（サンプル値）。
- 実データ版は Notion から取得して **非公開 Artifact とローカル `Private/Y-tion/`** にのみ反映。
- 毎朝の同期手順は **[SYNC.md](./SYNC.md)** を参照。

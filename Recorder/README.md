# Recorder — 声の受け皿

PLAUD と SwitchBot AIマインドクリップの録音を取り込んだ場所。
取り込みは Claude Code のスキル `recorder-inbox`（`/recorder-inbox`）から。

| 場所 | 中身 |
| --- | --- |
| `Recordings/` | 録音1本＝1ノート。要約・やること・ハイライト・おもいで・引用 |
| `Transcripts/` | 話者付きの文字起こし全文 |
| `Diary/` | その日の記録。おもいでと、その日出たやることが集まる |
| `TODO.md` | **やることの管理場所。チェックはここだけで行う** |
| `Inbox/` | SwitchBot アプリから書き出したファイルの置き場 |
| `dashboard.html` | スマホから見る用のダッシュボード（生成物） |

## 書いていいところ

各ノートの `<!-- recorder:begin -->` 〜 `<!-- recorder:end -->` は再取り込みで
上書きされる。**その下の「## メモ」以降は消えない**ので、自分の言葉はそこに書く。
frontmatter に自分で足したキーも残る。

## やることの流れ

1. 録音から抽出されたやることが `TODO.md` に集まる
2. 終わったら `TODO.md` でチェックを入れる
3. 次の取り込みで「完了」へ移動する（30日で表示から外れる）

文面を直したいときは、`TODO.md` ではなく元の録音ノートを直して取り込み直す。

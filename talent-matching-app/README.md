# 🎯 ハイクラス人材マッチング

要件（職種・役職レベル・経験年数・業界・想定年収・勤務地・語学・マネジメント規模・キーワード）を入力すると、
条件に合致する候補者を**適合度スコア順**に提示するプロトタイプアプリです。

## 使い方

`index.html` をブラウザで開くだけで動作します（ビルド不要・完全ローカル・外部通信なし）。

1. 左側のフォームで要件を入力
2. 「候補者を検索」を押す
3. 右側に適合度40%以上の候補者がスコア順に表示される

## 仕組み

- **職種**はハードフィルタ（指定するとその職種のみが対象）
- それ以外の項目は**ソフトスコアリング**。各要件を0〜1で評価し、重み付き平均で適合度(%)を算出
- 指定しなかった項目はスコアの分母から除外されるため、条件を絞るほど評価が厳密になります
- 経験年数・想定年収は「指定なし／上限なし」の状態を持ち、設定した場合のみ評価されます
- 各候補者カードには、加点理由（緑バッジ）と不足点（グレーバッジ）が表示されます

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面・フォーム・スタイル |
| `app.js` | スコアリングエンジンと描画ロジック |
| `candidates.js` | 候補者データ |

## ⚠️ 注意

**候補者データはすべて架空のサンプル**です。実在の人物とは一切関係ありません。
実運用する場合は `candidates.js` を実際の人材データベースに差し替えてください。
